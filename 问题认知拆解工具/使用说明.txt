# 问题认知拆解工具 - 使用说明

## 文件夹结构说明

```
问题认知拆解工具/
├── src/              # 源代码文件夹
│   ├── pages/        # 页面组件
│   │   ├── Home.tsx  # 输入页面
│   │   └── Result.tsx # 结果页面
│   └── App.tsx       # 主应用组件
├── dist/             # 构建好的成品网页（可直接打开）
│   └── index.html    # 网页入口文件
├── README.md         # 项目详细说明文档
├── package.json      # 项目依赖配置
└── 使用说明.txt      # 本文件
```

## 如何使用

### 方式一：直接打开成品网页（推荐）

1. 进入 `dist` 文件夹
2. 双击打开 `index.html` 文件
3. 即可在浏览器中使用问题认知拆解工具

### 方式二：开发模式运行（需要Node.js）

如果您想修改代码或重新构建：

1. 确保已安装 [Node.js](https://nodejs.org/)
2. 在当前目录打开命令行/终端
3. 运行以下命令：
   ```bash
   npm install
   npm run dev
   ```
4. 浏览器会自动打开应用

### 方式三：重新构建

如果您修改了代码，需要重新构建：

```bash
npm run build
```

新的构建文件会生成在 `dist` 文件夹中。

## 注意事项

- 当前版本使用模拟数据演示功能
- 如需连接真实AI服务，请修改 `src/pages/Home.tsx` 中的模拟分析逻辑
- 项目使用 React + TypeScript + Tailwind CSS 技术栈
